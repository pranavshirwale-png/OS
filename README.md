this program demonstrates process management in Linux. First, it accepts integer values and creates a child process using fork(). The parent process sorts the numbers in ascending order, and the child sorts them in descending order using Bubble Sort. Then waitpid() is used to synchronize the processes. Finally, the program demonstrates zombie and orphan processes. A zombie occurs when the child terminates but its status is not collected, whereas an orphan occurs when the parent terminates before the child.
